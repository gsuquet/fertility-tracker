# ADR 0000: Title of the decision

- **Date:** YYYY-MM-DD
- **Status:** Proposed
- **Decision makers:** Names

Copy this file to `NNNN-short-title.md`. Use the next free number. The sections come from the [MADR template](https://adr.github.io/madr/). A reference to this record always has the prefix, for example "ADR 0003".

The status is **Proposed**, **Accepted**, **Deprecated** or **Superseded**. A superseded ADR gives the number of the ADR that replaces it.

## Context and problem

Give the problem in two or three sentences. Write it as a question when possible.

## Decision drivers

- Give each force or requirement that affects the decision.

## Options

## Decision

Give the selected option and the reason in one or two sentences.

### Consequences

- Good: a result that the project wants.
- Bad: a cost or a risk that the project accepts.

### Confirmation

Tell how the project verifies the decision, for example a test, a check or a review.

### Option name
