# Set the Peak Day

Use this procedure to set the Peak Day of a cycle yourself. Do this when your FertilityCare Practitioner tells you that the Peak Day is a different day.

The application finds the Peak Day automatically. The automatic Peak Day is the last day of fertile mucus in the cycle. A Peak Day that you set replaces the automatic Peak Day.

## Set a Peak Day

1. Open the day in the **Today** page or in the observation drawer.
2. Turn on the **Designate Peak Day (P)** switch.
3. Click **Save Observation**.

## Go back to the automatic Peak Day

1. Open the day that has the Peak Day that you set.
2. Turn off the **Designate Peak Day (P)** switch.
3. Click **Save Observation**.

## Result

The day shows the letter **P** in the paper chart. The three dry days after the Peak Day get light green stamps. The statistics use the new Peak Day.
