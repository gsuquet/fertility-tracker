# Start a new cycle

Use this procedure to tell the application where a cycle starts. The first day of a cycle is cycle day 1.

The application asks this question when you save the first day of bleeding after a day without bleeding.

## Answer the question when you save

1. Record a day with bleeding. Read [Record an observation](record-an-observation.md).
2. Click **Save Observation**. The **New Cycle Start?** dialog opens.
3. Click one of these buttons:
   - **Yes, Start New Cycle**: this day is cycle day 1 of a new cycle.
   - **No, Continue Current Cycle**: this day stays in the current cycle.
   - **Cancel**: the application does not save the day.

## Change the answer later

1. Open the day in the **Today** page or in the observation drawer.
2. Click **Start of New Cycle**. The button shows **(Yes)** or **(No)**.
3. Click **Save Observation**.

The **Start of New Cycle** button shows only on a day with a bleeding code.

## Result

The cycle picker shows the cycles. The paper chart shows each cycle in a different row.
