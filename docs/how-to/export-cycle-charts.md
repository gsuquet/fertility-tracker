# How-To: Export Cycle Charts

This guide explains how to generate export files (PDF, PNG, or JSON) from **Fertility Tracker** to share with your healthcare provider or store for personal recordkeeping.

---

## Exporting as PDF (Printable Clinical Report)

1. Click the **Export** button in the top navigation header.
2. In the Export Modal, select **PDF Report**.
3. Choose the target cycle(s) to include (e.g., _Current Cycle_ or _All Historical Cycles_).
4. Click **Generate PDF**.
5. Save the generated `.pdf` file to your device.

---

## Exporting as High-Resolution PNG

1. Navigate to the **Chart Row** view.
2. Click **Export** in the top navigation header.
3. Select **PNG Image**.
4. Click **Download Image**. The resulting file contains a full-width image of your paper chart row with stamps and observation codes.

---

## Exporting & Restoring JSON Backups

### Exporting JSON Data

1. Click **Export** in the top navigation header.
2. Select **JSON Data Backup**.
3. Click **Download Backup**. This generates a structured JSON file containing all cycles, observations, and manual overrides.

### Restoring Data from JSON Backup

1. Open the **Export / Data Settings** modal.
2. Click **Import Backup**.
3. Select your `.json` backup file from your local disk.
4. Confirm the import to populate your cycles.
