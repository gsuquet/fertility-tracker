# Delete all data

Use this procedure to remove all your observations from this browser. For example, do this after the tutorial or before you give the device to a different person.

> **WARNING:** You cannot undo this procedure. Make a backup first if you want to keep your data. Read [Back up and restore your data](back-up-and-restore-your-data.md).

## Procedure

1. Click **Practitioner PDF / PNG**. On a phone, click the menu button and then **Practitioner PDF / PNG**.
2. Click **Clear Data / Reset**. The **Delete all chart data?** dialog opens.
3. Click **Delete all data**.

## Result

The application has no observations. It also deletes the copy of unreadable data. The theme, the language and the welcome guide settings stay the same.
