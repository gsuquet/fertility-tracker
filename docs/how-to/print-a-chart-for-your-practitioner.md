# Print a chart for your practitioner

Use this procedure to make a PDF file or a paper copy of your chart. The file has the format of the 35-day Creighton paper chart.

## Before you start

- Record the observations of the cycles that you want to print.

## Procedure

1. Open the **Chart** page.
2. Click **Chart options** (⋮) and then **Share chart**. On a wide screen, you can also click **Practitioner PDF / PNG** in the header.
3. In **Cycles**, select the cycles that you want to print. The cycle of the cycle picker is selected at the start.
4. Click **Print or PDF**. The print dialog of your browser opens.
5. Select the printer, or select **Save as PDF**.
6. Click **Print** or **Save**.

To send an image instead, click **Download PNG** in step 4. The browser downloads a PNG file with the same chart.

## Result

You have a landscape chart with one row of 35 days for each cycle. The rows go from the oldest cycle to the newest cycle. The text of the chart is in the language of the application. The observation codes are the same in each language. The file name has the cycle number and the date, for example `fertility-tracker-chart-cycle-2-2026-10-27.pdf`. The PNG file has the same name with `.png`.
