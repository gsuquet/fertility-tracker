# Print a chart for your practitioner

Use this procedure to make a PDF file or a paper copy of your chart. The file has the format of the 35-day Creighton paper chart.

## Before you start

- Record the observations of the cycles that you want to print.

## Procedure

1. Click **Practitioner PDF / PNG**. On a phone, click the menu button and then **Practitioner PDF / PNG**.
2. In **PDF Export Scope**, select one of these options:
   - **Single Cycle**: select the cycle in **Select Cycle**.
   - **Multiple Cycles**: select the cycles in the list. Use **Select All** or **Deselect All** if necessary.
3. Click **Print / Save as PDF**. The print dialog of your browser opens.
4. Select the printer, or select **Save as PDF**.
5. Click **Print** or **Save**.

## Result

You have a landscape chart with one row of 35 days for each cycle. The rows go from the oldest cycle to the newest cycle. The file name has the cycle number and the date, for example `fertility-tracker-chart-cycle-2-2026-10-27.pdf`.
