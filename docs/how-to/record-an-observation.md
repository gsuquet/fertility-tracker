# Record an observation

Use this procedure to record the observation of one day. You can use the **Today** page or the observation drawer. Both have the same fields.

## Before you start

- Know the codes of your observation. Read [Observation codes](../reference/observation-codes.md).

## Record from the Today page

1. Click **Today**.
2. Select the date. Use **Previous Day**, **Next Day** or a date in the recent history list.
3. Enter the observation:
   - Type the code in **Direct Code Entry**. For example, type `10KLX3 I`.
   - Or click a group row, for example **Mucus**, and click the buttons of the group.
   - Or, to use the code of the day before, click ⋮ and then **Copy yesterday**.
4. If you had intercourse, turn on **I - Sexual Intercourse**.
5. Optional: click **Notes** and type a note.
6. Make sure that the status card shows the stamp that you expect.
7. Click **Save Observation**.
8. If the **New Cycle Start?** dialog opens, do the procedure in [Start a new cycle](start-a-new-cycle.md).

## Record from the observation drawer

1. Open the drawer:
   - Click **Log** in the header. On a phone, click **+**.
   - Or click a day in **Paper Chart Strip** or **Monthly Calendar**.
2. In **Date**, make sure that the date is correct. When the date has an observation, the drawer shows it. Change it or delete it.
3. Enter the observation in **Direct Code Entry** or with the buttons.
4. Click **Save Observation**.

## Change an observation

1. Open the day in the **Today** page or in the drawer.
2. Change the code or the buttons.
3. Click **Save Observation**.

## Delete an observation

1. Open the day in the **Today** page or in the drawer.
2. Click ⋮.
3. Click **Delete observation**.

## Hide the group rows

1. Click ⋮.
2. Click **Direct Code Only**. The forms show only the code field, the switches and the notes.

## Result

The application saves the observation in the browser. It calculates the stamp, the cycle day and the Peak Day again for all the days of the cycle.
